# سایت راست‌دسک (rastdesk.ir)

سایت محصول راست‌دسک به فارسی و انگلیسی، با پنل مدیریت. هم‌معماری با سایت راستین (`../website`): PHP ساده، بدون فریم‌ورک و بدون وابستگی به CDN.

## صفحه‌ها
| نشانی | محتوا |
|---|---|
| `/fa/` | لندینگ: هیرو با CTA (دموی رایگان، قیمت‌ها، کاتالوگ)، آمار، چرا راست‌دسک، کاربرد برای هر تیم، ۳۷ ماژول، هوش مصنوعی، اپ موبایل، اتصال‌ها، استقرار، قیمت‌ها، پرسش‌ها و فرم تماس سریع |
| `/fa/modules` | همهٔ ماژول‌ها با فیلتر نسخه |
| `/fa/modules/{slug}` | صفحهٔ اختصاصی هر ماژول (۳۷ صفحه) |
| `/fa/pricing` | چهار نسخه، کاربر اضافه، جدول مقایسهٔ کامل، توسعهٔ سفارشی |
| `/fa/demo` | فرم درخواست دمو (با نسخه، تعداد کاربر، استقرار و ماژول) |
| `/fa/catalog` | دانلود کاتالوگ PDF (با فرم یا مستقیم، از پنل قابل تنظیم) |
| `/fa/contact`، `/fa/blog` | تماس و وبلاگ |

نوار ثابت «تماس با فروش / درخواست دمو» روی موبایل همیشه پایین صفحه است.

## نصب
مثل سایت راستین (`../website/README.md`): محتوای این پوشه را در `public_html` دامنهٔ rastdesk.ir آپلود کنید، `config.sample.php` را به `config.php` کپی کنید، پوشه‌های `storage/` و `uploads/` را قابل نوشتن کنید و `/admin` را باز کنید.

## پنل مدیریت (`/admin`)
- **سرنخ‌ها و پیام‌ها:** فرم‌های دمو، تماس سریع، تماس و دانلود کاتالوگ؛ فیلتر، خروجی CSV و ارسال دوباره به مقصد
- **تنظیمات:** قیمت و سقف کاربر هر نسخه، قیمت کاربر اضافه، آپلود کاتالوگ جدید، روش دانلود کاتالوگ، نشانی مقصد هر فرم، اطلاعات تماس، شبکه‌های اجتماعی، متن‌های اصلی
- **وبلاگ** و **حساب کاربری**

## داده‌ها
- `data/modules.fa.php` و `data/modules.en.php`: ۳۷ ماژول (عنوان، شعار، توضیح، قابلیت‌ها، مخاطب، پایین‌ترین نسخه) استخراج‌شده از کاتالوگ آبان ۱۴۰۵. با تغییر این فایل‌ها، لندینگ، صفحهٔ ماژول‌ها، جدول مقایسه و کارت نسخه‌ها همه با هم به‌روز می‌شوند.
- `data/catalog/`: کاتالوگ پیش‌فرض (از وب در دسترس نیست و فقط از مسیر دانلود ارسال می‌شود).
- `lang/fa.php` و `lang/en.php`: متن‌های سایت.
