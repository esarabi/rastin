# سایت راستین (rastingroup.ir)

سایت چهارزبانه‌ی شرکت توسعه هوشمند راستین (فارسی، English، العربية، Türkçe) با پنل مدیریت.
با PHP ساده نوشته شده و به فریم‌ورک یا CDN خارجی وابسته نیست. فونت‌ها و تصاویر روی خود هاست هستند.

## نیازمندی‌ها
- PHP نسخه‌ی ۷٫۴ یا بالاتر (پیشنهاد: ۸٫۱+)
- افزونه‌های `pdo_sqlite` (یا `pdo_mysql`)، `mbstring`، `dom`، `curl`، `fileinfo`/`gd`
- وب‌سرور Apache یا LiteSpeed با `mod_rewrite` (روی هاست‌های cPanel و DirectAdmin معمولاً فعال است)

## نصب روی هاست
1. محتوای پوشه‌ی `website/` را در `public_html` آپلود کنید.
2. فایل `config.sample.php` را کپی کنید و نامش را `config.php` بگذارید. `base_url` را روی `https://rastingroup.ir` بگذارید.
   - پیش‌فرض SQLite است و نیازی به ساخت دیتابیس ندارد.
   - برای MySQL مقدار `driver` را `mysql` کنید و مشخصات دیتابیس را وارد کنید. جدول‌ها خودکار ساخته می‌شوند.
3. پوشه‌های `storage/` و `uploads/` باید قابل نوشتن باشند (دسترسی 755 یا 775).
4. نشانی `https://rastingroup.ir/admin` را باز کنید. بار اول از شما می‌خواهد حساب مدیر را بسازید.
5. در «تنظیمات سایت» نشانی مقصد فرم‌ها، شبکه‌های اجتماعی و متن‌ها را وارد کنید.
6. بعد از فعال شدن SSL، دو خط مربوط به HTTPS را در `.htaccess` از حالت توضیح خارج کنید.

## پنل مدیریت (`/admin`)
- **وبلاگ:** نوشتن و ویرایش مطلب برای هر زبان، تصویر شاخص، آپلود تصویر در متن، پیش‌نویس و انتشار زمان‌بندی‌شده
- **پیام‌ها و درخواست‌ها:** همه‌ی فرم‌های «تماس با ما» و «درخواست دمو» ذخیره می‌شوند، با خروجی CSV و امکان ارسال دوباره
- **تنظیمات سایت:** تلفن، ایمیل، نشانی، نقشه، لینک راست‌دسک، شبکه‌های اجتماعی، نشانی مقصد فرم‌ها، و متن‌های اصلی هر زبان
- **حساب کاربری:** تغییر رمز عبور

## ارسال فرم‌ها به نشانی مقصد
هر فرم پس از ثبت با درخواست `POST` به نشانی تعیین‌شده در تنظیمات فرستاده می‌شود (JSON یا فرم معمولی، با توکن Bearer اختیاری). نمونه‌ی JSON:
```json
{"form":"demo","lang":"fa","id":12,"submitted_at":"2026-11-05 10:30:00",
 "name":"...","company":"...","position":"...","phone":"0912...","email":"...",
 "interest":"speech","interest_label":"تحلیل صوت مکالمات","team_size":"51-200",
 "team_size_label":"۵۱ تا ۲۰۰ نفر","message":"...","page":"https://rastingroup.ir/fa/demo"}
```
اگر ارسال ناموفق باشد، پیام در پنل باقی می‌ماند و می‌توانید آن را دوباره ارسال کنید.

## ویرایش متن‌ها
متن‌های هر زبان در `lang/fa.php`، `lang/en.php`، `lang/ar.php` و `lang/tr.php` است. ساختار هر چهار فایل یکی است.
متن‌های اصلی (تیتر خانه، شعار، نشانی، توضیح گوگل) از پنل مدیریت هم قابل تغییر است.

## اجرای محلی
```bash
cd website && cp config.sample.php config.php && php -S localhost:8000 index.php
```

## امنیت
- رمزها با `password_hash` ذخیره می‌شوند و ورود پس از ۵ تلاش ناموفق ۱۵ دقیقه قفل می‌شود.
- همه‌ی فرم‌ها توکن CSRF دارند. فرم‌های عمومی تله‌ی ربات (honeypot) و محدودیت تعداد ارسال دارند.
- HTML مطالب هنگام ذخیره پاک‌سازی می‌شود و اجرای PHP در پوشه‌ی `uploads` غیرفعال است.
- پوشه‌های `app`، `lang`، `views` و `storage` از وب قابل دسترسی نیستند.
