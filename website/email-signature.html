راهنمای نصب

جیمیل (Gmail)
  1. روی «کپی امضا» بزنید.
  2. در جیمیل: چرخ‌دنده ⚙ ← See all settings ← زبانه‌ی General ← بخش Signature.
  3. Create new را بزنید، نامی بدهید و در کادر امضا Ctrl+V بزنید.
  4. پایین صفحه Save Changes را بزنید.
اوت‌لوک (Outlook) ویندوز
  1. روی «کپی امضا» بزنید.
  2. در اوت‌لوک: File ← Options ← Mail ← Signatures.
  3. New را بزنید، نامی بدهید و در کادر ویرایش Ctrl+V بزنید.
  4. در «Choose default signature» امضا را برای پیام‌های جدید و پاسخ‌ها انتخاب کنید و OK بزنید.
اوت‌لوک وب (Outlook.com / Microsoft 365)
  1. تنظیمات ⚙ ← Mail ← Compose and reply.
  2. امضا را در کادر Email signature بچسبانید و Save بزنید.
راندکیوب (Roundcube) — ایمیل روی هاست
  1. تنظیمات ← هویت‌ها (Identities) را باز کنید و هویت خود را انتخاب کنید.
  2. کنار کادر امضا، گزینه‌ی امضای HTML را فعال کنید.
  3. در نوار ابزار ویرایشگر دکمه‌ی <> (Source code) را بزنید، کد HTML را از دکمه‌ی «نمایش کد HTML» همین صفحه کپی و جایگزین کنید.
  4. ذخیره را بزنید.
اپل‌میل (Apple Mail)
  1. Mail ← Settings ← Signatures و با + امضای جدید بسازید.
  2. تیک Always match my default message font را بردارید و امضا را بچسبانید.

تصویرهای امضا از سایت rastingroup.ir بارگذاری می‌شوند. اگر گیرنده تصاویر را نبیند، برنامه‌ی ایمیلش نمایش تصاویر را مسدود کرده است؛ متن امضا همچنان خوانا می‌ماند.
