# کاتالوگ راستین

کاتالوگ ۸ صفحه‌ای معرفی شرکت (فارسی، A4).

| فایل | کاربرد |
|---|---|
| `build/rastin-catalog-digital.pdf` | ارسال با ایمیل، پیام‌رسان و دانلود از سایت (لینک‌ها کلیک‌خورند) |
| `build/rastin-catalog-print-3mm-bleed.pdf` | چاپ: اندازه‌ی ۲۱۶×۳۰۳ میلی‌متر با ۳ میلی‌متر حاشیه‌ی برش از هر طرف |
| `build/page-*.png` | پیش‌نمایش صفحه‌ها |

برای چاپ: صحافی منگنه‌ای (۸ صفحه = ۲ برگ A3 تاشده)، کاغذ گلاسه‌ی ۱۷۰ گرم برای داخل و ۳۰۰ گرم برای جلد پیشنهاد می‌شود.
فایل چاپی RGB است؛ چاپخانه آن را به CMYK تبدیل می‌کند. پیش از تیراژ نهایی، نمونه‌ی چاپی (پروف) بگیرید تا رنگ مرجانی (#FF5A36 ≈ Pantone 171 C) بررسی شود.

متن‌ها از فایل زبان سایت (`website/lang/fa.php`) خوانده می‌شود. پس از تغییر متن‌ها:
```bash
tools/build_catalog.sh
```
