# Rastin Intelligent Development — Brand

Brand assets for توسعه هوشمند راستین (rastingroup.ir).

- `brand/logo/` — logo SVGs (text outlined), PNG exports, favicon
- `brand/fonts/` — Vazirmatn (SIL OFL)
- `brand/guidelines/index.html` — brand book
- `tools/` — scripts that regenerate logos and the brand book
  (`pip install fonttools uharfbuzz`, then `python3 tools/build_logos.py && python3 tools/build_guidelines.py`)

Product name: **راست‌دسک** (RastDesk) — rastdesk.ir
